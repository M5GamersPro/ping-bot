# 🏓 بوت بينج ديسكورد المتطور بلغة رستم (Rust Ping Bot)

بوت ديسكورد احترافي وعالي الأداء ومبني بالكامل باستخدام لغة **Rust** وإطار العمل **Poise** (المعتمد على مكتبة `serenity`). تم تصميم هذا البوت لتقديم أدق وأسرع استجابة لقياس سرعة اتصاله مع خوادم ديسكورد والخادم المستضيف.

## ✨ المميزات الرئيسية
* **هجين بالكامل (Hybrid):** يدعم تنفيذ نفس الأمر بالطريقتين: الأوامر المائلة المباشرة (`/ping`) أو باستخدام البادئة التقليدية (`!ping`).
* **قياس مزدوج لزمن الاستجابة (Dual Latency):** 
  * يحلل سرعة اتصال الـ API الخاص بديسكورد (API Latency).
  * يقيس سرعة معالجة خادم الاستضافة وإرسال الرسائل (Client Latency).
* **مؤشر أداء ذكي:** تتغير ألوان بطاقة العرض الـ (Embed) ديناميكيًا حسب جودة الاتصال (🚀 أخضر للأداء الممتاز، 🟡 برتقالي للأداء المتوسط، 🔴 أحمر عند وجود بطء أو لاق).
* **خفيف ومتوافق مع الأجهزة الضعيفة:** تم تحسين الكود ليعمل بكفاءة تامة حتى داخل بيئات الموبايل مثل **Termux** على نظام أندرويد.

---

## 🛠️ المتطلبات الأساسية
تأكد من تثبيت الأدوات التالية على نظامك (أو داخل تطبيق Termux):
* بيئة عمل لغة رستم **Rust & Cargo** (الإصدار 2021 أو أحدث).
* حساب مطور في ديسكورد للحصول على رمز البوت (Bot Token) من [Discord Developer Portal](https://discord.com).

---

## 🚀 طريقة التثبيت والتشغيل

### 1. استنساخ المشروع وإعداد الملفات
قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع (بجانب ملف `Cargo.toml`) وضع فيه رمز البوت الخاص بك:
```env
DISCORD_TOKEN=ضع_هنا_توكن_البوت_الخاص_بكامل
```

### 2. تفعيل صلاحيات الرسائل (Intents)
من لوحة التحكم الخاصة بالمطورين في ديسكورد (Discord Developer Portal)، اذهب إلى تبويب **Bot** ثم قم بتفعيل خيار:
* **Message Content Intent** (ليتمكن البوت من قراءة أمر `!ping`).

### 3. بناء وتشغيل البوت

#### 💻 للتشغيل على خادم عالي الأداء أو الحاسوب الشخصي:
```bash
cargo run --release
```

#### 📱 للتشغيل الآمن داخل تطبيق Termux (لتجنب إغلاق المعالج بسبب القيود):
```bash
cargo run --release -j 1
```
*(يقوم الأمر `-j 1` بإجبار المترجم على بناء حزمة واحدة تلو الأخرى لتفادي استهلاك كامل موارد الهاتف وإغلاق التطبيق فجأة).*

---

## 📜 طريقة الاستخدام داخل السيرفر
بمجرد تشغيل البوت بنجاح، سيقوم تلقائيًا بتسجيل الأوامر المائلة على ديسكورد. يمكنك استخدام الأوامر التالية في أي قناة نصية:
* `/ping` (أمر مائل مدمج مع واجهة ديسكورد).
* `!ping` (الأمر التقليدي باستخدام البادئة).
